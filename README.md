# VEIL/01

An interactive product-site concept for a speculative privacy wearable. The experience combines an original SVG product model, scroll-driven narrative, a simulated camera view, an exploded anatomy view, finish configurator, and a local-only reservation flow.

> VEIL/01 is a design concept, not a certified security device. The interface deliberately avoids unverified anonymity or performance claims.

## Experience highlights

- Cursor-reactive hero product model
- GSAP scroll choreography and staged text reveals
- Interactive camera-vision simulation
- Hover-driven exploded product anatomy
- Three-finish product configurator
- Responsive layout and reduced-motion support
- GitHub Pages deployment workflow

## Run locally

```bash
npm install
npm run dev
```

Build the production bundle:

```bash
npm run build
```

## Stack

React 19, Vite 7, GSAP 3, semantic SVG, and custom CSS.
